# Belarbi Brahim Portfolio

This is a complete one-page portfolio website for the Yassir Driver Acquisition Agent application.

## Before publishing
Replace these placeholders in `belarbi-brahim-portfolio.html`:
- YOUR_EMAIL@example.com
- +213 XX XX XX XX
- ADD YOUR LINKEDIN URL
- English and German language levels

## Get a public Portfolio URL
Upload the HTML file to a static hosting service such as GitHub Pages, Netlify, or Cloudflare Pages.
The resulting public `https://...` address is what you can paste into Yassir's "Portfolio link" field.
